# Job Portal System

A modern Java-based web application for job seekers and recruiters to search, apply, and post job opportunities.

## Features
- **Job Search & Filtering**: Styled banner with live keyword and location filtering.
- **User Registration & Login**: Account management for Job Seekers, Recruiters, and Admins.
- **Job Applications**: Online application forms with quick modal overlays.
- **Clean UI**: Custom CSS styling and responsive layouts.

## Tech Stack
- **Backend**: Java (built-in HttpServer & JDBC)
- **Database**: MySQL
- **Frontend**: HTML5, CSS3, JavaScript

## How to Run
`ash
# Compile source files
javac -cp lib/*;src -d bin src/*.java

# Run WebServer
java -cp lib/*;bin WebServer
`
